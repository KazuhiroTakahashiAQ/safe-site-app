# 事故・品質事例提案くん（デモ）

建設現場の工程に応じて、当日起こり得る災害事例と品質不具合事例を確認できるデモアプリです。
**単一HTMLファイル（`index.html`）で動作します**（ビルド不要、CSS/JS/事例データはすべて `index.html` に内蔵）。

## GitHub Pages

- https://KazuhiroTakahashiAQ.github.io/safe-site-app

## 主な機能

- 工程表（ガントチャート）上で日付ラインをドラッグして事例を抽出
  - 下段は左右2カラム：左に災害事例、右に品質不具合事例
  - 品質事例は日替わりローテーション（その日の工程に対応する全件から、日付で決まる重点10件を表示）
  - 横スクロールしても工程名は左端に残ります
- 事例カードは概要のみ表示し、原因・是正・再発防止策などの詳細は「詳細表示」で展開
- 画像クリックで拡大表示、モーダル内でページ送り
- 写真で判別：現場写真から工種候補を提示し、その工種の品質不具合事例と関連する安全（災害）事例を表示（デモ版は決め打ち判定。本番ではLLMの画像認識を想定）
- 災害事例ライブラリ（9件）／不具合事例ライブラリ（3工種・全60件、工種フィルタ付き）

## 品質不具合事例について

- 対象は躯体系の3工種（鉄筋工事／コンクリート工事／鉄骨工事）、各20件・計60件。
- 工程表タブでは、その日の工程カテゴリに対応する工種の事例を右カラムに表示します（地下・基礎／躯体・コンクリ→鉄筋・コンクリート、鉄骨・躯体→鉄骨）。他工種は準備中です。
- 事例は公開資料の不具合パターンを一般化・蒸留したもので、実在の現場・企業・製品を特定する情報は含みません。
- 事例イラストはAI生成の模式図です。判別タブのサンプル写真は Wikimedia Commons のフリー素材で、出典とライセンスは `CREDITS.md` に記載しています（コンクリート写真の看板部分はモザイク処理済み）。

## ファイル構成

- `index.html` — アプリ本体（単一ファイル）
- `image-assets/` — 災害事例の資料画像
- `quality-illust/` — 品質事例のイラスト
- `quality-photos/` — 写真判別用のサンプル写真
- `tools/` — `index.html` の生成用（`template.html` に `data.json` を埋め込んで生成。データは旧React版から `extract-data.mjs` で抽出）

## ローカルで開く

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## GitHub Pages デプロイ

`index.html` と画像資産フォルダを `gh-pages` ブランチへ反映すると、GitHub Pages の自動ビルドが走って公開されます（master への push ではデプロイされません）。
