# 事故事例提案くん

建設現場の工程に応じて、当日起こり得る災害事例を確認できるデモアプリです。
品質不具合事例の提示機能も統合されています（下記「品質不具合事例（統合機能）」参照）。

## GitHub Pages

- https://KazuhiroTakahashiAQ.github.io/safe-site-app

## 主な機能

- 工程表（ガントチャート）上で日付ラインを動かして事例を抽出
- 選択日の事例一覧（件数・画像枚数付き）
- 画像クリックで拡大表示、モーダル内でページ送り
- 災害事例ライブラリ
- 工程表の下部は左右2カラム：左に災害事例、右に品質不具合事例を表示
- 写真で判別（品質）：現場写真から工種候補を提示し、その工種の不具合事例を表示（デモ版は決め打ち判定）
- 品質事例ライブラリ（3工種・全60件）

## 品質不具合事例（統合機能）

- 対象は躯体系の3工種（鉄筋工事／コンクリート工事／鉄骨工事）、各20件・計60件。
- 工程表タブでは、その日の工程カテゴリに対応する工種の事例を右カラムに表示します（地下・基礎／躯体・コンクリ→鉄筋・コンクリート、鉄骨・躯体→鉄骨）。他工種は準備中です。事例は日替わりローテーションで、その日の重点10件が日付に応じて切り替わります（同じ日は同じ顔ぶれ）。
- 事例は公開資料の不具合パターンを一般化・蒸留したもので、実在の現場・企業・製品を特定する情報は含みません。
- 事例イラストはAI生成の模式図です。判別タブのサンプル写真は Wikimedia Commons のフリー素材で、出典とライセンスは `CREDITS.md` に記載しています（コンクリート写真の看板部分はモザイク処理済み）。
- 工種判別はデモ用の決め打ちです。本番ではLLMの画像認識で判別する想定です。
